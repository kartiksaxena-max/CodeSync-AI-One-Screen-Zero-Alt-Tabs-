# 90-second demo script

Record the screen at 1080p. Turn Wi-Fi off before you start and show the Wi-Fi icon once.

| Time | On screen | Say |
|---|---|---|
| 0:00-0:10 | The messy way: a video window, a slides window, a code editor, alt-tabbing between them. Keep it fast and a little painful. | "Learning to code means juggling a video, slides and an editor, and losing your place every time." |
| 0:10-0:20 | CodeSync AI with the same lesson in one window. | "CodeSync AI puts it all on one screen. It runs offline on a Snapdragon laptop." |
| 0:20-0:45 | Pause the video on the teacher's code. Click Capture, drag over the code, add it to the editor. Show the highlighted lines with time chips. | "Pause on the teacher's code and capture it. The AI reads the frame, fixes the indentation and the mistakes it can catch using the lesson's own words, and adds it to my editor." |
| 0:45-0:55 | Click a chip on line 3. The video jumps to the moment. | "Every line remembers when the teacher wrote it. Click it and you are back at that explanation." |
| 0:55-1:05 | Type a wrong answer at the checkpoint, get a hint, then pass. | "Checkpoints pause the video until you try it yourself. Hints come in steps." |
| 1:05-1:20 | Open the performance panel and show the measured CPU vs NPU table. | "Here is the same task on the CPU and the Snapdragon NPU on this laptop, measured just now." |
| 1:20-1:30 | Hindi captions on, Wi-Fi still off. | "It works with no internet, with Hindi captions, for students on modest laptops." |

Only show the NPU table if you ran it on a Snapdragon laptop. If you did not, leave that section out and say so in the write-up.
